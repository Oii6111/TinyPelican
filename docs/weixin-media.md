# 微信图片和文件收发

TinyPelican 的微信渠道按腾讯 [openclaw-weixin](https://github.com/tencent/openclaw-weixin) 的 iLink 协议实现。此次核对版本为 `874637a0dbc24050f72d1385add4fc6170a2d726`。

## 使用

- 在设置中扫码登录微信，并先从微信给机器人发送一条消息，建立 `context_token`。
- 微信发送给机器人的图片和文件自动保存到应用数据目录的 `media/weixin`，可在「对话」中的对应微信会话预览图片或下载文件。关闭自动回复后仍保存收到的附件。
- 「消息渠道 → 微信」可以选择图片或文件，填写可选说明，然后点击发送。只发送给当前登录绑定的微信用户；选中文件不会立即发送。
- Agent 生成文件后，在回复中使用独立的一行 `MEDIA:<绝对本地路径>`，由渠道上传并发送附件。附件必须位于应用工作目录或数据目录，配置、凭据和内部记录不能自动作为附件发送。
- 每个文件最大 100 MB。图片支持 PNG、JPEG、GIF、WebP；其他格式以文件发送。附件保留原始名称，本地保存使用随机标识，避免覆盖或目录穿越。
- 图片可传给支持图片的模型；普通文件通过 DSH 原生上传接口提交完整字节和原始名称，以会话专属附件凭证进入对话。附件保存成功不代表模型支持识图或所有文件格式；DSH 的 `read` 工具仅读取文本，其他格式由 Agent 使用可用 Skills/文档工具处理。
- 当前 DSH 不会自动解析 Office 文件；旧版 `.doc` 和 `.docx` 需要各自适用的文档工具。附件处理规则要求先检查可用能力，避免启动桌面应用或 COM；无法读取时报告实际限制。此规则是 Agent 指引，不是系统级进程拦截。

## 协议与接口

上传流程：`getuploadurl` → AES-128-ECB/PKCS7 加密 → CDN POST → 读取 `x-encrypted-param` → `sendmessage`。图片消息项类型为 2，文件为 4；上传类型分别为 1、3。说明文字和附件分别发送一个消息项。

接收兼容 CDN 完整 URL 和 `encrypt_query_param`，支持图片 hex 密钥、base64 原始密钥及 base64 hex 密钥。媒体访问限定微信 HTTPS CDN，下载有超时和体积限制，不向 CDN 传递机器人凭据。

- `POST /api/wechat/media`：二进制文件，`X-Filename` 为 URL 编码名称，返回附件标识和安全显示信息。
- `GET /api/wechat/media/:id`：图片预览或文件下载；`?download=1` 强制下载。遵循现有 API 登录验证。
- `POST /api/wechat/send`：`{ "attachmentId": "...", "text": "可选说明" }`，显式发送并记录成功发送的内容。
- `GET /api/history`：微信会话消息可包含 `attachments`。前端不接收本地路径、CDN 查询凭据或解密密钥。

附件不会写入联系人微信导入库，也不会自动执行其中的内容。传输失败会显示错误；发送部分成功时只保留真实成功结果，不重复发送整组附件。
