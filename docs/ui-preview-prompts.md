# 日历与日程 UI 预览提示词

## 预览图一：日历工作台

Use case: ui-mockup
Asset type: high-fidelity desktop productivity app interface preview
Primary request: redesign the provided calendar and schedule screen into a shippable, human-designed desktop productivity product. Use the attached calendar screenshot as a functional reference only: preserve the Chinese information architecture and calendar behavior, but create a substantially more restrained visual system.
Input images: Image 1 is a reference for the existing calendar layout; do not copy its visual styling.
Scene/backdrop: a real desktop app window at 1440 x 1000, warm near-white background, subtle top app chrome, generous but purposeful spacing.
Subject: a monthly calendar workspace for “日历与日程”, with a compact page title, month navigation, a seven-column calendar, and a focused agenda rail for the selected day.
Style/medium: polished production UI mockup, editorial information design, calm and tactile, closer to a thoughtfully designed independent software product than a design-system showcase.
Composition/framing: left 68% is the calendar; right 32% is a single-day agenda rail. Use a compact header and a thin secondary toolbar instead of five summary cards. Calendar cells are flat and quiet with hairline dividers, not individually floating cards. Selected date uses one dark ink outline and a very small accent marker. Agenda entries are dense rows with time, title, context, and a slim status rule. Include one subtle “今天” indicator and one overdue item.
Lighting/mood: neutral daylight, focused, dependable, quiet.
Color palette: ink #202321, warm paper #F7F6F2, muted stone #D8D6CE, one restrained terracotta accent #B76542, desaturated sage for completed items. No gradients.
Materials/textures: crisp typography, slight paper-like warmth, 1px borders, no glassmorphism, no glossy shadows, no excessive rounded rectangles.
Text (verbatim): “日历与日程”, “2026年10月”, “今天”, “全部日程”, “待办”, “提醒”, “16:00  项目讨论”, “确认国庆期间能否带江苏月逛苏州大学”, “六壹今天需询问之前看漏的消息事项”. Render Chinese text accurately and keep it legible.
Constraints: keep the interface realistic and implementable; show clear hierarchy and practical density; use familiar monochrome line icons only; use no emoji; no fake analytics dashboard; no decorative illustrations; no excessive whitespace; no giant title; no card grid at the top.
Avoid: AI-generated landing-page aesthetic, Dribbble concept art, neon colors, purple gradients, floating glass panels, excessive pill buttons, heavy drop shadows, random badges, oversized empty panels, unreadable tiny text, English placeholder copy, watermarks.
