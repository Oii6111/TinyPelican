# 版本开发启动约定

开发环境和安装包使用同一套本地版本包资源，但启动入口有明确区别：

- `npm start` / `npm run start:base`：启动通用版。
- `npm run start:romance`：启动恋爱版。
- `npm run dist`：打包包含 `base` 和 `romance` 的完整安装包，不代表只打恋爱版。

开发启动命令只强制本次启动的初始版本，不覆盖已保存的版本选择。运行中通过“切换版本”输入预设码后，版本选择会保存并在内部重启时生效；下次重新执行 `npm start` 仍从通用版开始。

安装包不使用开发强制变量，会读取用户保存的版本选择。新安装默认进入通用版，输入 `TINYPELICAN-ROMANCE` 后切换到恋爱版。
