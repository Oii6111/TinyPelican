后台日志

这里显示小鹈鹕在后台做的事：剪贴板捕获、意图识别、主动提醒、关系维护、微信推送等。

选择左侧联系人查看档案

语音待回填

复制聊天记录后，系统会在这里列出「语音」占位。你按顺序复制转写文字，就会自动回填；也可以手动跳过不要的条目。

意图识别

新聊天归档后自动识别任务 / DDL / 日程 / 事项提醒 / 等待回复。高置信度自动添加并推送，中低置信度在这里确认。

设置

用于归档时排除自己，只为「对方」建档。
对标记 ⭐ 的联系人，超过“冷落天数”没联系时推送问候建议。
例如 7 表示 7 天没联系就提醒。
免打扰时段内不推送主动提醒，等结束后再补推。
支持跨天，例如 23:00 - 08:00。
保存后需重启监听器（watch-clipboard.ps1）才生效。
